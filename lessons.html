How Lessons Work + Resources

Lessons hosted on:

Lessons are online, interactive, and tailored to each student so support stays flexible and effective.

Sessions are hosted online so it is easy to join from anywhere.

Platforms used:

  • Google Meet
  • Zoom

Please install one of the options above before your session and test audio and video in advance.

Lesson Structure

The structure is adapted to each student's needs and evolves as progress is made.

A typical lesson will include:

  1. Introduction of content
  2. Guided teaching with questioning to check understanding
  3. Exam question example
  4. Student attempts exam-style question with support if needed
  5. Recap of the lesson
  6. Recommended independent practice resources

Resources

After each session, students can receive targeted resources based on the topics covered. These are designed for independent practice and confidence building between lessons.

Any questions from this work can be brought to the next lesson and reviewed together.

The resources link requires a password. Access is provided after booking.
