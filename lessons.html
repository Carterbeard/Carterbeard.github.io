How Lessons Work

Lesson Structure:

The structure is adapted to each student's needs and evolves as progress is made. A typical lesson will include:

  • Introduction of content

    Topic context and any pre-checks on prior understanding.

  • Guided teaching with questioning

    Clear explanations with active questioning to check understanding as we go.

  • Worked exam example

    A model approach shown through a real exam-style question.

  • Student attempt with support

    The student attempts an exam-style question independently, with guidance available if needed.

  • Recap of the lesson

    Key points consolidated and any remaining questions addressed.

  • Recommended independent practice resources

    Targeted resources suggested for work between sessions.

Resources:

After each session, students can receive targeted resources based on the topics covered. These are designed for independent practice and confidence building between lessons.

Any questions from this work can be brought to the next lesson and reviewed together.

The resources link requires a password. Access is provided after booking.
